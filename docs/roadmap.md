ROOTCLOUD — Roadmap

This roadmap describes the current development direction of ROOTCLOUD.

The roadmap is indicative and may change according to technical findings, testing results and user requirements.

Phase 1 — Project Foundation

Status: In progress

Define project name

Define project vision

Define initial architecture

Create public GitHub repository

Document initial architecture

Document project vision

Define initial deployment environment

Define development standards

Phase 2 — Prototype Infrastructure

Status: Planned / In progress

Prepare virtualization environment

Deploy Proxmox VE

Deploy OPNsense

Configure internal network

Deploy Nextcloud

Deploy MinIO

Configure secure remote access

Test storage workflows

Document deployment procedures

Status: Planned

Firewall policies

Monitoring

Security hardening

Status: Planned

Define backup architecture

Implement automated backups

Define retention policy

Test restoration

Evaluate service redundancy

Identify single points of failure

Phase 5 — ROOTBOX

Status: Concept

Define ROOTBOX architecture

Test recovery and synchronization

Phase 6 — Monitoring and Operations

Status: Planned

Infrastructure monitoring

Service monitoring

Development Philosophy

ROOTCLOUD follows an iterative development approach.

The project prioritizes:

Functional prototype
Security
Reliability
Documentation
Testing
Scalability
Production readiness

Features will be considered production-ready only after appropriate testing and validation.
